Descrição

Site para cadastrar e consultar agentes virtuais de uma equipe. Cada agente
possui nome, especialidade, tarefa que executa, responsável e matrícula. O
site tem uma página inicial de apresentação, uma página com a listagem dos
agentes em cards e uma página com o formulário de cadastro.

Páginas

- **index.html** — página inicial com apresentação e navegação.
- **agentes.html** — listagem da coleção de agentes em cards.
- **cadastro.html** — formulário de cadastro de um novo agente.

Pré-requisitos

- Um navegador web atual (Chrome, Firefox, Edge, etc.).
- Nenhuma instalação é necessária nesta fase (site estático em HTML e CSS).

Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador (duplo clique ou arraste para a aba).
3. Navegue entre as páginas pelo menu no topo.

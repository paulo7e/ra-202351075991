Início

Este sistema serve para cadastrar e consultar agentes virtuais da equipe. Cada agente possui um nome, uma especialidade, a tarefa que executa, um responsável e uma matrícula.

Use o menu acima para ver a lista de agentes já cadastrados ou para cadastrar um novo agente.
